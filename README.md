# VIPER: Variational Inference for Pattern Extraction and Recognition in Genomics

Reference implementation for the VIPER model described in the paper:
"Variational Inference for Pattern Extraction and Recognition in Genome Sequences using State Space Models for Cancer Detection"

This repository contains preprocessing, model definition, training, and evaluation code.

## Setup
pip install -r requirements.txt

## Training
python train.py

## Evaluation
python eval.py
